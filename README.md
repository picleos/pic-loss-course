# PIC Loss Evaluation Course

An online course on evaluating the loss of photonic integrated circuit (PIC) devices: how to measure insertion loss on a fiber-coupled setup, and how to separate it into coupling, propagation and S-bend losses with least squares.

**Open the course:** https://picleos.github.io/pic-loss-course

## Contents

| Part | Topic |
|---|---|
| 1 | Introduction and loss budget |
| 2 | Optical power and the decibel scale |
| 3 | Optical setup and fiber–chip alignment |
| 4 | Polarization and insertion loss |
| 5 | Decomposing insertion loss: the cut-back method |
| 6 | Linear Algebra I: linear regression |
| 7 | S-bend loss: physical origins |
| 8 | S-bend test patterns and extraction |
| 9 | Linear Algebra II: least squares |
| 10 | Summary and references |

## Features

- English and Korean, switchable on every page
- Concept checks and 7 exercises with randomly generated problems, automatic grading and worked solutions
- Interactive widgets (dB converter, mode overlap, S-bend loss calculator, least squares playground)
- Progress is saved in the visitor's browser; no account and no server needed
